# 同步時直接寫進 Obsidian 資料夾，以標記區分條文與條筆記

法規修正後要重新匯出，又不能蓋掉使用者寫在條文檔裡的條筆記。我們決定由網頁直接寫入使用者授權的 Obsidian 資料夾（電腦版 Chrome / Edge 的資料夾存取功能），條文檔中用 Obsidian 不顯示的註解標記框出「條文區塊」，同步時只換掉這個區塊、把舊條文移到可收合的「修正前條文」，標記以外的條筆記一律不動。

## Considered Options

- 條文與筆記分開兩個檔案，筆記用 `![[…]]` 嵌入條文：不必寫入資料夾，但每一條要維護兩個檔，筆記不再「掛在條上」。
- 下載 zip 讓使用者自己覆蓋：最簡單，但很容易蓋掉筆記。

## Consequences

- 同步只能在電腦版 Chrome / Edge 做（使用者在家用 Windows 電腦），手機與 Safari 只能閱讀，不能同步。
- 條文區塊的標記格式一旦有使用者的資料夾在用，就不能隨意更改，否則舊檔案認不出條文區塊。
- 使用者若手動改了條文區塊裡的文字，下次同步會被換掉（舊內容會留在修正前條文）。
