# 法規查閱與匯出（Law-Export-Lab）

在瀏覽器查閱全國法規資料庫的法律與命令，並匯出成 Word（.docx）或 Markdown（.md，適合 Obsidian）。

## 功能

**閱讀**
- 搜尋法規名稱或簡稱（例如「刑法」「道交條例」），網頁上直接閱讀；有編章節目錄、條文內容搜尋、跳到指定條號、一鍵複製
- 項次與款目縮排比照全國法規資料庫
- **條文引用變成連結**：「第四十七條第一項」「刑事訴訟法第二百五十二條」點了就跳過去（「前項」這類相對說法不處理）
- 修正沿革、字體大小調整、手機版（法規清單與目錄改成抽屜）
- **背誦模式**：遮住整條逐項翻開，或只遮住刑度、金額、期間等數字

**做筆記（Obsidian）**
- 「我的法規」清單：選定要放進 Obsidian 的法規
- **同步到 Obsidian**（電腦版 Chrome / Edge）：直接寫進 Obsidian 資料夾的「法規/法規名稱/」，一條一個檔案，另有法規總覽（目錄＋沿革）
  - 只更新條文區塊，你寫的條筆記與自訂屬性不會動
  - 條文有修正時，舊條文保留在可收合的「修正前條文」
  - 屬性：法規、條號、編章節、修正日期、資料日期；簡稱當別名，`[[刑法第10條]]` 也連得到
  - 條文引用會變成 Obsidian 連結，連到該條或該項（區塊連結 `#^p2`）
- 沒辦法同步時，也可以下載「一條一檔」zip 或「整部一檔」Markdown

**其他**
- 下載 Word：目錄、標題層級、項次表格排版、A4、頁碼、修正沿革
- **自動更新**：GitHub Actions 每天從法務部抓一次資料；打開網頁時只下載有變動的法規並提示
- 連不上網路時仍可閱讀上次保存的版本；也可以把法務部的 zip 拖進網頁使用

名詞定義見 [CONTEXT.md](CONTEXT.md)，同步方式的決定見 [docs/adr/0001](docs/adr/0001-sync-into-obsidian-folder.md)。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁版面與樣式 |
| `js/core.js` | 法規結構、項款目、條文引用、簡稱、沿革的解析 |
| `js/export.js` | Obsidian 與 Word 匯出 |
| `js/sync.js` | 同步到 Obsidian 資料夾（保留筆記） |
| `js/data.js` | 資料下載、快取、使用者設定 |
| `js/ui.js` | 畫面與操作 |
| `vendor/jszip.min.js` | 讀取 zip、產生 Word 與 zip 檔 |
| `scripts/build_data.py` | 下載法務部資料，拆成一部法規一個檔案 |
| `tests/` | 解析與同步邏輯的測試（部署前自動執行） |
| `.github/workflows/update-data.yml` | 每天臺灣時間 03:17 測試、下載資料並部署網頁 |

法規資料不放在 repo 裡，每次部署時才從法務部下載，所以 repo 很小。

## 第一次設定

1. 到 repo 的 **Settings → Pages**，把 **Source** 改成 **GitHub Actions**
2. 到 **Actions** 頁面，選「更新法規資料並部署網頁」→ **Run workflow**
3. 完成後，網址會是 `https://thehsiuhsiu.github.io/Law-Export-Lab/`

## 注意

- 如果 repo 連續 60 天沒有任何更新，GitHub 會自動暫停每天的排程，並寄信通知。這時到 Actions 頁面按 **Enable workflow** 就能恢復。
- 法務部的資料下載如果失敗，或筆數明顯不對，這次就不會部署，網頁會繼續使用上一版資料。

## 資料來源

法務部全國法規資料庫，依[政府資料開放授權條款第 1 版](https://data.gov.tw/license)釋出。條文以全國法規資料庫公告為準。
